## ✨ What I Build & Deliver

- ✅ **Scalable backends** – Modular NestJS apps with dependency injection, clear separation of concerns, and easy unit/integration testing.
- ✅ **High-performance frontends** – Next.js with Core Web Vitals optimization, image optimization, streaming SSR, and partial pre-rendering.
- ✅ **Type-safe full-stack** – End-to-end TypeScript, shared types between frontend and backend, Prisma for type-safe database operations.
- ✅ **Real-time features** – Live notifications, chat, collaborative editing via WebSockets (Socket.io + NestJS Gateway).
- ✅ **Secure by design** – Implement JWT refresh rotation, OAuth2, rate limiting, CSRF protection, and security headers.
- ✅ **Smooth UI/UX** – Tailwind CSS with dark mode, responsive design, accessibility (a11y), and micro-interactions.
- ✅ **Production ready** – Docker multi-stage builds, GitHub Actions for linting/testing/deployment, monitoring with Sentry/Logtail.
